# Oracle Local Setup

## Current behavior
The application chooses the Todo repository based on configuration:

- If `OracleDatabase:ConnectionString` is empty, it keeps using the in-memory repository.
- If `OracleDatabase:ConnectionString` has a value, it switches to the Oracle-backed repository.

## Fill these values
Update `appsettings.Development.json` or use environment variables:

```json
{
  "OracleDatabase": {
    "ConnectionString": "",
    "Schema": "",
    "TableName": "TODOS"
  }
}
```

Example connection string shape:

```text
User Id=;Password=;Data Source=localhost:1521/FREEPDB1;
```

Example with a schema value:

```text
Schema=MYFIRSTAPI
```

## Required table
Create this table in your Oracle schema:

```sql
CREATE TABLE TODOS (
    ID NUMBER GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
    TITLE VARCHAR2(200) NOT NULL,
    IS_COMPLETED NUMBER(1) DEFAULT 0 NOT NULL
);
```

## Environment variable option
You can override configuration without editing files:

```text
OracleDatabase__ConnectionString=
OracleDatabase__Schema=
OracleDatabase__TableName=TODOS
```

## Notes
- `Schema` can be blank if the connected user already owns the `TODOS` table.
- `TableName` is validated and only supports letters, numbers, and underscore.
- The Oracle repository supports the same CRUD endpoints already exposed by the API.
